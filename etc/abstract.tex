\chapter*{Abstract}
\label{cha:abtract}
\addcontentsline{toc}{chapter}{Abstract}

Over the years, Linux kernel developers have introduced a vast number
of powerful tracing capabilities. Linux userspace and kernel
developers, system administrators, performance enginners and alikes
rely and benefit from these tracing capabilities to monitor, debug and
secure their systems. In this work we first discuss the tracing
methods available for the Linux kernel as of verion 7.0, we then focus
on eBPF, its design and importance, we finally present Kivebpf as a
case study for an application that uses eBPF in a Kubernetes cluster
for security monitoring.
