\subsubsection*{tracefs}

TODO


We interface with ftrace through tracefs. Ftrace creates the tracefs file
system, this is usually mounted in sysfs in `/sys/kernel/tracing`. We will refer
to the location where tracefs is mounted as `/TRACEFS` throughout this
discussion. There are multiple tracers available under
\verb|/TRACEFS/available_tracers|.  You specify a tracer in
\verb|/TRACEFS/current_tracer|, activate tracing with \verb|/TRACEFS/tracing_on|
and read traces in `/TRACEFS/trace` or \verb|/TRACEFS/trace_pipe|
consumer. Error are written to \verb|/TRACEFS/error_log|.
